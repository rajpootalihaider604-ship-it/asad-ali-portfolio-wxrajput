ASAD ALI — PROFESSIONAL DIGITAL MARKETING PORTFOLIO

CONTENTS
- index.html: portfolio website
- style.css: responsive visual design
- script.js: mobile navigation and active navigation state
- assets/asad-ali.png: supplied profile image

PREVIEW
Open index.html in a modern browser. Internet is needed for the Google Fonts to load; the website itself works without them using fallback fonts.

EDIT CONTACT DETAILS
Search index.html for the email address and WhatsApp URL if you want to change contact details.

PUBLISH WITH VERCEL
1. Extract this ZIP.
2. Upload the files and assets folder to a GitHub repository (keep the folder structure).
3. In Vercel, choose Add New > Project and import that repository.
4. For a static HTML site, leave Build Command and Output Directory blank unless Vercel asks otherwise, then deploy.

NOTES
This portfolio uses a clean, premium dark theme and responsive layout. It describes services and working approach without inventing client testimonials, results, or case-study metrics.
